How a function hides a subgroup

In ℤ₁₂, the three elements 0, 4 and 8 all have the same remainder modulo 4. So do 1, 5 and 9. Each set of matching answers is a coset.

The promise on the function

Take a known group G, an unknown subgroup H and a function f whose outputs label the left cosets of H. A left coset is the translate xH = {xh ∣ h ∈ H}. The promise says exactly when two inputs get the same label.

f(x) = f(y)  ⟺  xH = yH  ⟺  x⁻¹y ∈ H.

The hidden subgroup problem asks for generators of H given access to f. Here f(x) = x mod 4, and a single generator 4 describes the entire subgroup ⟨4⟩ = {0, 4, 8}.

What a quantum query gives you

Start with a uniform superposition over a finite group and compute f into a second register. Measuring the output picks a coset uniformly. Its elements still share one coherent superposition in the input register.

|xH⟩ = (1/√|H|) ∑h ∈ H |xh⟩.

For outcome 1 in the explorer, the input becomes (|1⟩ + |5⟩ + |9⟩)/√3. The unknown offset changes between runs. The common spacing survives, and the Fourier transform makes it measurable.

Why change the group?

Shor used periodicity in Abelian groups to factor integers and compute discrete logarithms. This matters for RSA and Diffie–Hellman. Regev found a connection to lattice-based cryptography. An algorithm that can read hidden reflections from dihedral coset states, with the error tolerance in his theorem, could find a uniquely short direction in a lattice. The rest of the guide follows what changes when a rotation and a reflection can no longer be interchanged.

Why Fourier sampling works

A character turns the group operation into multiplication of phases. On a finite Abelian group, the characters that assign phase 1 to every hidden element tell us exactly which subgroup we have.

Characters are homomorphisms

A character χ maps G to the complex unit circle with χ(xy) = χ(x)χ(y). The characters form the dual group Ĝ under pointwise multiplication. On ℤN, choosing where 1 goes determines the whole character, so χk(x) = exp(2πikx/N) for k ∈ ℤN.

The character sum either adds or cancels

The QFT sends |x⟩ to a sum over character labels with amplitudes χ(x)/√|G|. On a coset |xH⟩, the amplitude for χ is proportional to

∑h ∈ H χ(xh) = χ(x) ∑h ∈ H χ(h).

If χ is 1 on H, the inner sum is |H|. Otherwise pick h₀ ∈ H with χ(h₀) ≠ 1. Multiplication by h₀ permutes H, so multiplying the sum by χ(h₀) leaves it unchanged. Only zero has that property.

Back to ℤ₁₂

For H = ⟨4⟩, we need χk(4) = exp(2πik/3) = 1. The four surviving Fourier labels are 0, 3, 6 and 9, each with probability ¼. The offset of the observed coset contributes only a phase.

Reconstructing the subgroup

The surviving characters form the annihilator H⊥. Independent Fourier samples are uniform on this dual subgroup. Once the samples generate it, intersect their kernels to recover H. For example, χ₃ alone generates the four labels above, and its kernel is exactly {0, 4, 8}.

Discrete log in two coordinates

Suppose g generates a cyclic group of known order r, and h = gs. The function f(u,v) = guh−v on ℤr² hides the line ⟨(s, 1)⟩. Fourier transforming both coordinates gives a pair (c,d) satisfying cs + d ≡ 0 mod r. For example, take r = 10. A sample (1, 7) gives s = 3. When c is invertible modulo r, the same calculation gives s = −d/c mod r.

Order finding

For a unit a modulo N, exponentiation is a homomorphism from (ℤ, +) into (ℤ/Nℤ)ˣ. Its kernel is rℤ, where the order r is the first positive exponent that returns to 1.

How Shor reads the period

With Q exponent values in the register, a peak at bin k gives k/Q ≈ s/r. Standard factoring chooses a power of two with N² ≤ Q < 2N². This gives continued fractions the resolution to recover the reduced fraction from a good sample. The denominator is r when s and r are coprime. Candidate orders can be tested by modular exponentiation. The circuit above keeps Q = 1,024 fixed so you can compare different orders on the same scale.

If r is even and ar/2 ≢ −1 mod N, the two gcds of ar/2 ± 1 with N yield nontrivial factors. With a = 2, N = 15, the order is 4. Then gcd(4 − 1, 15) = 3 and gcd(4 + 1, 15) = 5.
